# IPW — Insurance Portal Workflow

Projeto final (LEIC 2025/2026) — Aplicação Web para gestão do *workflow* de averiguação de sinistros.

Estado: Em desenvolvimento.

## Visão geral
**Objetivo:** Desenvolver uma plataforma Web integrada para gestão do *workflow* de averiguação de sinistros, destinada a centralizar processos, normalizar procedimentos e suportar a colaboração estruturada entre todos os intervenientes, garantindo maior eficiência, controlo e transparência.

**Funcionalidades (planeadas):**
- Autenticação e autorização, com pelo menos os papéis: administrador, gestor de processo e averiguador
- Criação e gestão de processos de averiguação
- Atribuição manual de processos a averiguadores
- Sistema de validação com múltiplos níveis (submissão, análise e aprovação)
- Registo de histórico de alterações e decisões por processo
- Anexação e gestão de documentos associados aos processos
- *Dashboard* administrativo com indicadores operacionais e monitorização

**Funcionalidades opcionais:**
- Atribuição automática de processos com base em critérios configuráveis
- Integração com o projeto *Insurance Reporter App* (IRA)
